# 📊 Nifty100 Analytics Platform

An end-to-end financial analytics platform built using **Python, SQLite, Streamlit, and Plotly** to analyze Nifty100 companies through financial ratios, valuation metrics, stock screening, peer comparison, and interactive dashboards.

---

## 🚀 Project Overview

Developed using an Agile sprint-based workflow.

### ✅ Sprint 1 — Data Foundation
- ETL pipeline for Nifty100 datasets
- SQLite analytical database
- Data cleaning and validation

### ✅ Sprint 2 — Financial Ratio Engine
- 20+ financial KPIs
- Profitability, leverage, CAGR & cash flow analysis
- Automated ratio validation

### ✅ Sprint 3 — Screener & Peer Analytics
- Financial screener engine
- 6 investment presets
- Composite Quality Score
- Peer comparison analytics

### ✅ Sprint 4 — Dashboard & Valuation
- Interactive Streamlit dashboard
- 8 analytics screens
- Valuation module
- QA testing & bug fixes

## 🚀 Getting Started

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the dashboard:

```bash
streamlit run src/dashboard/app.py
```

Dashboard URL:

```
http://localhost:8501
```
